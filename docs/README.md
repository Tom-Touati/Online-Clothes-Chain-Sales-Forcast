# Documents

- `decision_log.md`: every decision and experiment of the project, append-only, with the commands, the scores and the verdict.
  Entries `D389i`–`D422` cover the final system; earlier entries the path to it. File paths are those of the project folder
  (`FILE_MAP.tsv` maps them to this repository).
- `EDA_REPORT.md`: the data analysis, including the 15 data artefacts and their treatment.
- `pages/`: three self-contained interactive pages: the item explorer (each item's history, past forecasts and projection), the
  atlas (pipeline, data, decisions) and the error study (where and why the forecast misses).
- `FILE_MAP.tsv`: each file's path in the project folder and in this repository.
