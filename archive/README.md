# Archive

Everything from the project that the current solution does not use, at the path it had in the project folder: about 380 scripts
(`archive/eda/`) with their run logs, the tables of rejected or superseded experiments (`archive/data/`), earlier pages, server
copies, reports and coordination notes. The decision log ([`docs/decision_log.md`](../docs/decision_log.md)) describes each experiment
and names its files by these paths (`eda/…` here is `archive/eda/…`, or `pipeline/…` for the scripts in use; see
[`docs/FILE_MAP.tsv`](../docs/FILE_MAP.tsv)).
